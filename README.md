# Django Todo Application

A simple Todo Management application built using **Django** as part of my learning process. 
This project helps understand Django fundamentals like authentication, authorization, CRUD operations, templates, models, and database handling.

## 🚀 Features

### User Authentication
- User Registration
- User Login
- User Logout
- User Authorization (users can access only their own tasks)

### Todo Management
- Create new tasks
- View tasks
- Update existing tasks
- Delete tasks
- Set deadlines for tasks
- Deadline display in **red color** when required

## 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- Bootstrap
